# Summit Shelter - Premium Tent Ecommerce Website

A modern, dark-themed landing page for a premium tent-selling ecommerce website built with React, Vite, Tailwind CSS, and Framer Motion.

![Summit Shelter](https://x.com/i/status/2050178808771379459)

## 🏕️ Features

- **Dark Space Theme**: Premium dark navy background with liquid glass UI effects
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop
- **Smooth Navigation**: Scroll-to-section navigation with mobile hamburger menu
- **Video Background**: Cinematic hero section with video background
- **Premium Typography**: Anton for headings, Condiment for accents
- **Liquid Glass Effects**: Modern glassmorphism UI throughout
- **Real Product Images**: High-quality tent images from Unsplash
- **Performance Optimized**: Lazy loading images, minimal animations

## 🚀 Tech Stack

- **React 18** - UI library
- **Vite** - Build tool and dev server
- **Tailwind CSS 3** - Utility-first CSS framework
- **Framer Motion** - Animation library
- **Lucide React** - Icon library

## 📦 Installation

```bash
# Clone the repository
git clone <your-repo-url>

# Navigate to project directory
cd tent-hero

# Install dependencies
npm install

# Start development server
npm run dev
```

## 🛠️ Development

```bash
# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 🎨 Design System

### Colors
- **Background**: `#010828` (Deep dark navy)
- **Text**: `#EFF4FF` (Cream)
- **Accent**: `#6FFF00` (Neon green)

### Typography
- **Headings**: Anton (Google Fonts)
- **Accents**: Condiment (Google Fonts)
- **Body**: Monospace

### Components
- Liquid glass navigation bar
- Full-screen mobile menu
- Product gallery with 6 featured tents
- About section with featured product
- Newsletter subscription
- Footer with social links

## 📱 Sections

1. **Hero** - Full-screen video background with headline and CTA
2. **Gallery** - 6 premium tent products with prices
3. **About** - Collection information and featured product
4. **Footer** - Newsletter signup, navigation, and social links
